    Your route

      Section 2 · Quick review

      What you already know

      Two ideas from junior forms carry this whole chapter: sample spaces, and the mean and variance of a set of data.

      Sample space and event

      For a random experiment, the set of all possible outcomes is the sample space樣本空間 S. Each outcome is a sample point. A set of some sample points is an event事件, named with a capital letter. When all sample points are equally likely, P(E) = n(E) ÷ n(S).

      Try it

      A fair dice is thrown once. Pick an event.

      Mean, variance and standard deviation of data

      For data x1, …, xn with frequencies f1, …, fn:

      \[\bar{x}=\frac{\sum x_i f_i}{\sum f_i},\qquad \sigma^2=\frac{\sum (x_i-\bar{x})^2 f_i}{\sum f_i},\qquad \sigma=\sqrt{\sigma^2}\]
      Key link

      Data: 5, 5, 8, 8, 8, 14

      Datum x5814Total
      Frequency f2316

      Mean = (5 × 2 + 8 × 3 + 14 × 1) ÷ 6 = 48 ÷ 6 = 8. Variance = [(5 − 8)² × 2 + 0 × 3 + (14 − 8)² × 1] ÷ 6 = 54 ÷ 6 = 9, so σ = 3.

      Why this matters

      Once each frequency is divided by the total, the mean becomes Σ x × (relative frequency). In this chapter the relative frequency is replaced by a probability, and the same formula gives the expectation E(X). Keep this picture in mind.

      Section 3 · 9.1A

      Random variables

      Textbook: Example 9.1, 9.2Classwork 9.1, 9.2

      A bag contains 1 purple ball and 1 white ball. Two balls are drawn one by one with replacement. Let X be the number of purple balls drawn. Every outcome of the experiment gives one number for X.

      Animation

      Draw, then follow the arrow

      Purple bars: relative frequency from your draws. Amber marks: the theoretical probabilities ¼, ½, ¼. The more you draw, the closer they get.

      Definition

      A random variable隨機變量 is a rule that gives a number to every sample point of an experiment. We name it with a capital letter such as X, and write its values with the small letter x.

      A discrete random variable離散隨機變量 takes values that can be listed one by one: a finite list (0, 1, 2) or an endless list (1, 2, 3, …).

      Notice
      • Each sample point gives exactly one value of X.
      • One value can come from several sample points: WP and PW both give X = 1.
      • So "X = 1" is an event, and P(X = 1) makes sense.
      Watch the wording
      • "With replacement": the bag is the same for every draw.
      • "Without replacement": the bag changes after each draw, so probabilities change too.
      • Values can be negative, e.g. a net gain of −$5.
      Try it

      Discrete or not? If discrete, can you list all the values?

      Definition

      \(P(X=x)\) is the probability function概率函數 of \(X\). It gives a probability to each possible value of \(X\) and must satisfy

      \[\text{(a)}\;\; 0\le P(X=x)\le 1 \text{ for every possible } x,\qquad \text{(b)}\;\; \sum P(X=x)=1.\]

      The list of all possible values together with their probabilities is the discrete probability distribution離散概率分佈 of \(X\).

      Try it

      Is each table a probability distribution?

      Check both conditions every time. One failure is enough to say no.

      Worked example

      Finding an unknown

      The table shows the probability distribution of \(X\). Find the value of \(k\).

      x1234
      P(X = x)0.2\(k^2\)\(0.5k\)0.3

      Try it on paper first, then reveal one step at a time.

      1. The probabilities must add up to 1.

        \[0.2+k^2+0.5k+0.3=1\]
      2. \[k^2+0.5k-0.5=0\quad\Longrightarrow\quad (k-0.5)(k+1)=0\]\[k=0.5\ \text{ or }\ k=-1\]

      3. Test each root against \(0\le P(X=x)\le 1\). When \(k=-1\), \(P(X=3)=0.5(-1)=-0.5<0\), which is impossible. Reject \(k=-1\).

      4. \(k=0.5\). Check: \(0.2+0.25+0.25+0.3=1\) ✓

      Whenever a quadratic gives two roots, write the rejected one with a reason, e.g. "(rejected since P(X = 3) < 0)". Marks are often given for this line.

      As the number of plays grows, the relative frequencies approach the probabilities, so the average approaches 10(0.5) + 50(0.3) + 200(0.2) = 60.

      Definition

      The expectation (or expected value)期望值 of a discrete random variable \(X\), written \(\mu\) or \(E(X)\), is

      \[\mu=E(X)=x_1p_1+x_2p_2+\cdots+x_np_n=\sum xP(X=x)\]

      It is a weighted mean of the values of \(X\), with the probabilities as weights. It is the long-run average, so it need not be a value that \(X\) can actually take.

      Explore

      E(X) is the balance point

      Think of each probability as a weight placed at x. Add or remove weight; the triangle moves to where the bars balance.

      Expectation of a function of X

      If \(g(X)\) is a function of \(X\), weight each value \(g(x)\) by \(P(X=x)\):

      \[E[g(X)]=\sum g(x)P(X=x),\qquad\text{e.g. } E(X^2)=\sum x^2P(X=x)\]
      Example

      X takes 1, 2, 3 with probabilities 0.2, 0.5, 0.3

      x123Sum
      P(X = x)0.20.50.31
      xP(X = x)0.210.9E(X) = 2.1
      x²P(X = x)0.222.7E(X²) = 4.9

      Notice E(X²) = 4.9 but [E(X)]² = 2.1² = 4.41. They are not equal. The gap between them turns out to be the variance (next section).

      Fair game

      If $G is a player's net gain in one game, the game is fair公平遊戲 when E(G) = 0. If E(G) < 0, the player loses money in the long run.

      Section 7 · 9.2B

      Variance Var(X)

      Textbook: Example 9.11, 9.12Classwork 9.11, 9.12

      Expectation tells you the centre. Variance tells you how widely the values spread around that centre.

      Compare

      Same mean, different spread

      Contributions to the variance, (x − μ)² × P(X = x), stacked:

      Definition

      The variance方差 of \(X\) is the expected squared distance from the mean:

      \[\sigma^2=\operatorname{Var}(X)=E[(X-\mu)^2]=\sum (x-\mu)^2P(X=x)\]

      A more convenient formula:

      \[\operatorname{Var}(X)=E(X^2)-[E(X)]^2,\quad\text{where } E(X^2)=\sum x^2P(X=x)\]

      The standard deviation標準差 is \(\sigma=\sqrt{\operatorname{Var}(X)}\). It has the same unit as \(X\).

      Why are the two formulas the same? \[\begin{aligned}\operatorname{Var}(X)&=\sum (x^2-2\mu x+\mu^2)P(X=x)\\&=\sum x^2P(X=x)-2\mu\sum xP(X=x)+\mu^2\sum P(X=x)\\&=E(X^2)-2\mu\cdot\mu+\mu^2\cdot 1\\&=E(X^2)-\mu^2\end{aligned}\]
      Step through

      Building the working table

      X takes 0, 1, 2, 3 with probabilities 0.1, 0.2, 0.3, 0.4. Find E(X) and Var(X).

      Common mistakes
      • Writing E(X²) = [E(X)]². They are different numbers.
      • Forgetting to square E(X) in Var(X) = E(X²) − [E(X)]².
      • Giving σ when asked for Var(X), or the other way round.
      • A negative variance means an arithmetic slip somewhere. Variance is never negative.

      Section 8 · 9.2C

      E(aX + b) and Var(aX + b)

      Textbook: Class Activity 9.2Example 9.13, 9.14, 9.15

      Lab

      Expectation
      Variance
      Property

      For a discrete random variable \(X\) and constants \(a\), \(b\):

      \[E(aX+b)=aE(X)+b\qquad\qquad \operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)\]

      So the standard deviation of \(aX+b\) is \(|a|\sigma\).

      Why b disappears from Var

      Adding b slides every bar, and the mean, by the same amount. Distances from the mean do not change, so the spread does not change.

      Why a becomes a²

      Multiplying by a stretches every distance from the mean by |a|. Variance uses squared distances, so it is multiplied by a². This is also why Var(−X) = Var(X).

      A two-line proof

      Let \(Y=aX+b\). Then \(E(Y)=\sum(ax+b)P(X=x)=a\sum xP(X=x)+b\sum P(X=x)=a\mu+b\).

      Each deviation is \(y-E(Y)=(ax+b)-(a\mu+b)=a(x-\mu)\), so \(\operatorname{Var}(Y)=\sum a^2(x-\mu)^2P(X=x)=a^2\operatorname{Var}(X)\).

      Common mistakes
      • Var(2X + 3) = 2Var(X) + 3 ✗  →  correct: 4Var(X)
      • Var(3 − 2X) = −2²Var(X) ✗  →  correct: (−2)²Var(X) = 4Var(X)

      Skill A · two unknowns from ΣP = 1 and E(X)

      The probability distribution of \(X\) is shown, where \(a\) and \(b\) are constants. It is given that \(E(X)=1.5\). Find \(a\), \(b\) and \(\operatorname{Var}(X)\).

      x0123
      P(X = x)\(a\)0.3\(b\)0.2

      1. Sum of probabilities: \(a+0.3+b+0.2=1\), so \(a+b=0.5\ \cdots\ (1)\)

      2. Use the expectation:

        \[0(a)+1(0.3)+2b+3(0.2)=1.5\ \Longrightarrow\ 2b=0.6\ \Longrightarrow\ b=0.3\]

      3. From (1): \(a=0.2\)

      4. \[E(X^2)=0^2(0.2)+1^2(0.3)+2^2(0.3)+3^2(0.2)=3.3\]\[\operatorname{Var}(X)=3.3-1.5^2=1.05\]
      Skill B · decisions using expected profit

      A bakery makes a special cake each morning at a cost of $120 each and sells it for $300. Unsold cakes are thrown away at closing time. The daily demand \(D\) has this distribution:

      d123
      P(D = d)0.20.50.3

      (a) Find the expected daily profit if 2 cakes are made. (b) Should the bakery make 1, 2 or 3 cakes each day?

      1. Key idea: the number sold is the smaller of the demand and the number made. Cost is paid on every cake made.

      2. (a) Make 2: cost \(=2\times120=\$240\).
        If \(D=1\): profit \(=300-240=\$60\). If \(D\ge2\): profit \(=600-240=\$360\), with \(P(D\ge2)=0.8\).

      3. \[\text{Expected profit}=60(0.2)+360(0.8)=\$300\]

      4. (b) Make 1: every day 1 cake is sold, profit \(=300-120=\$180\).

      5. Make 3: cost \(\$360\). Profits are \(-60,\ 240,\ 540\) for \(D=1,2,3\).

        \[\text{Expected profit}=-60(0.2)+240(0.5)+540(0.3)=\$270\]

      6. Compare \(\$180,\ \$300,\ \$270\). The bakery should make 2 cakes each day.

      Skill C · unknowns in Y = aX + b

      \(X\) is a random variable with \(E(X)=4\) and \(\operatorname{Var}(X)=2.25\). Let \(Y=aX+b\), where \(a\) and \(b\) are constants. If \(E(Y)=10\) and \(\operatorname{Var}(Y)=9\), find \(a\) and \(b\).

      1. \[\operatorname{Var}(Y)=a^2\operatorname{Var}(X)\ \Longrightarrow\ 9=2.25a^2\ \Longrightarrow\ a^2=4\ \Longrightarrow\ a=2\ \text{ or }\ -2\]
      2. \[E(Y)=aE(X)+b\ \Longrightarrow\ 10=4a+b\]

      3. If \(a=2\): \(b=10-8=2\). If \(a=-2\): \(b=10+8=18\).

      4. \(a=2,\ b=2\) or \(a=-2,\ b=18\). Keep both unless the question says \(a>0\).

      Skill D · is the game fair?

      A player pays $12 to spin a wheel once. The prize is $0 with probability \(\frac12\), $10 with probability \(\frac13\) and $40 with probability \(\frac16\). Let $\(W\) be the prize and $\(G\) the net gain.

      (a) Find \(E(G)\). Is the game fair? (b) What fee would make the game fair?

      1. \[E(W)=0\left(\tfrac12\right)+10\left(\tfrac13\right)+40\left(\tfrac16\right)=\tfrac{10}{3}+\tfrac{20}{3}=10\]

      2. \(G=W-12\), so by the property of expectation:

        \[E(G)=E(W)-12=-2\]

      3. \(E(G)\ne0\), so the game is not fair. In the long run the player loses $2 per game.

      4. (b) For a fee of $\(k\): \(E(W-k)=10-k=0\), so the fee should be $10.
