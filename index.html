      The mean is 8. How far are the data from 8, on average?

      Press Start to see where the variance formula comes from.

      1. Deviation \(=x_i-\bar{x}\):   \(-3,\ -3,\ 0,\ 0,\ 0,\ 6\)
        A deviation is the signed distance from the mean. Their sum is always 0, so averaging them tells us nothing.
      2. Square them: \((x_i-\bar{x})^2\) = 9, 9, 0, 0, 0, 36
        Squaring makes every distance positive. Picture each one as a square: far data make big squares.
      3. \(\sum (x_i-\bar{x})^2 f_i=(5-8)^2\times2+(8-8)^2\times3+(14-8)^2\times1=54\)
        Add up all the square areas. The frequency fi counts each datum the right number of times.
      4. \(\sigma^2=\dfrac{\sum (x_i-\bar{x})^2 f_i}{\sum f_i}=\dfrac{54}{6}=9\)
        Variance = the average square area. Share the total area of 54 equally among the 6 data.
      5. \(\sigma=\sqrt{9}=3\)
        Standard deviation = the side of that average square. It is back in the same unit as the data, so we can draw it on the number line: most data lie within x̄ ± σ.
      Watch out Variance vs standard deviation
      • Variance σ² is in squared units (marks², $²). Standard deviation σ is in the original unit.
      • Give the one the question asks for.

      After dividing, the mean is Σ x × (relative frequency). In this chapter, relative frequency is replaced by probability, and the same formula gives the expectation E(X).

      Definition

      A random variable隨機變量 is a rule that gives a number to every sample point.

      Notice One value, many sample points
      • Each sample point gives exactly one value of X.
      • One value can come from several sample points: WP and PW both give X = 1.
      • So "X = 1" is an event, and P(X = 1) makes sense.
      Definition

      A discrete random variable離散隨機變量 takes values that can be listed one by one: a finite list (0, 1, 2) or an endless list (1, 2, 3, …).

      Example 9.1

      Write down all possible values

      Ex. 9A #1–3

      In each experiment, write down all possible values of the random variable.

      1. (a)Football teams A and B play 3 matches. X = number of matches that team A wins.
      2. (b)A bag has 3 gold coins and 4 silver coins. Coins are drawn one by one without replacement until a gold coin is obtained. Y = number of draws required.
      3. (c)W = number of people entering a shop in an hour.
      Hint

      Ask three questions: What is the smallest value? What is the largest value? Can it go on forever?

      Try it on paper first. Then press Start to reveal the solution one line at a time.

      1. (a) The possible values of \(X\) are 0, 1, 2 and 3.

        Team A can win none, some or all of the 3 matches. Each row in the diagram is one way to get each value.

      2. (b) At most 5 coins are drawn to obtain a gold coin.

        Think aloud: the worst case is that all 4 silver coins come out first. Then the 5th coin must be gold.

      3. The possible values of \(Y\) are 1, 2, 3, 4 and 5.

        Best case: the first coin is gold, so Y = 1. Every number from 1 to 5 can happen.

      4. (c) The possible values of \(W\) are all non-negative integers.

        Nobody may come (W = 0), and there is no fixed upper limit: 0, 1, 2, 3, … W is an infinite discrete random variable.
      Exam skill
      • List the values in increasing order.
      • For "until …" questions, find the worst case to get the largest value.
      • "All non-negative integers" means 0, 1, 2, …; "all positive integers" means 1, 2, 3, …. The difference is whether 0 is allowed.
      Example 9.2

      Values and probabilities from a sample space

      Ex. 9A #4

      Four balls marked 1, 1, 4 and 7 are in a bag. Two balls are drawn one by one randomly without replacement. X = number of balls marked 1; Y = sum of the two numbers.

      1. (a)Suppose (a, b) denotes getting a in the 1st draw and b in the 2nd. List the sample space.
      2. (b)Write down all possible values of X and Y.
      3. (c)Find P(X = 0) and P(Y = 11).
      Hint

      Draw a 4 × 4 grid: 1st draw down the side, 2nd draw across the top. The same ball cannot be drawn twice.

      Try it on paper first. Then press Start.

      1. (a) The sample space is \(\{(1,1),(1,4),(1,7),(4,1),(4,7),(7,1),(7,4)\}\).

        There are two balls marked 1, so (1, 1) is possible. The 12 grid cells are equally likely, but (1, 4) fills 2 cells while (4, 7) fills only 1. This sample space is not equiprobable, so you cannot just count outcomes.

      2. (b) The possible values of \(X\) are 0, 1 and 2.

        Count the balls marked 1 in each outcome. The colours in the grid show X.

      3. The possible values of \(Y\) are 2, 5, 8 and 11.

        Add the two numbers: 1 + 1 = 2, 1 + 4 = 5, 1 + 7 = 8, 4 + 7 = 11.
      4. \[P(X=0)=P(\{(4,7),(7,4)\})=\frac14\times\frac13\times2=\frac16\]
        X = 0 means neither ball is marked 1, so the balls are 4 and 7. P(4 then 7) = ¼ × ⅓ (one ball fewer on the 2nd draw). There are two orders, so × 2. The grid agrees: 2 of 12 cells.
      5. \[P(Y=11)=P(\{(4,7),(7,4)\})=\frac16\]
        Y = 11 happens only with 4 and 7. It is the same event as X = 0, so it has the same probability.
      Exam skill
      • Write the event as a set of sample points first, e.g. P({(4, 7), (7, 4)}).
      • If the sample space is not equiprobable, use multiplication along each order, not counting.

      Example 9.3

      Check for a valid probability distribution

      Ex. 9A #6, 7

      Determine whether each of the following is a probability distribution of X. Explain your answer.

      (a) x−213
      f(x)1/22/3−1/6
      (b) x0123
      f(x)0.050.150.20.7
      (c) x−0.50.60.91.5
      f(x)0.2850.3150.10.3
      Hint

      Test both conditions on every table. One failure is enough to say no.

      Try it on paper first. Then press Start.

      1. For a probability function: (i) \(0\le P(X=x)\le1\) for all possible \(x\); (ii) \(\sum P(X=x)=1\).

        Think aloud: these are the two tests. The shaded band in the diagram is 0 to 1; every bar must stay inside it.

      2. (a) ∵ \(f(3)=-\frac16<0\)

        ∴ \(f(x)\) is not a probability function.

        ∴ It is not a probability distribution of \(X\).

        A probability can never be negative. Notice ½ + ⅔ − ⅙ = 1, so the sum test alone would be fooled.

      3. (b) For all defined values \(x\), \(0\le f(x)\le1\).

        \[\textstyle\sum f(x)=0.05+0.15+0.2+0.7=1.1>1\]

        ∴ \(f(x)\) is not a probability function. ∴ It is not a probability distribution of \(X\).

        Each bar is fine, but stacking them overflows past 1 (see the meter).

      4. (c) For all defined values \(x\), \(0\le f(x)\le1\).

        \[\textstyle\sum f(x)=0.285+0.315+0.1+0.3=1\]

        ∴ \(f(x)\) is a probability function. ∴ It is a probability distribution of \(X\).

        Both tests pass. Negative or decimal x values are fine: only the probabilities are restricted.
      Exam skill
      • Write the reason for each test, using ∵ and ∴.
      • End with a full conclusion sentence: "It is (not) a probability distribution of X."
      Example 9.4

      Find the unknown

      Ex. 9A #8–10

      The table shows all possible values x of a discrete random variable X and its probability function. Find the value of k.

      x1234
      P(X = x)0.20.10.4kk² + 0.1
      Hint

      What do all the probabilities add up to? After solving, test each answer against 0 ≤ P(X = x) ≤ 1.

      Try it on paper first. Then press Start.

      1. ∵ \(\sum P(X=x)=1\)

        \[\therefore\ 0.2+0.1+0.4k+(k^2+0.1)=1\]
        The only fact you know about the unknown: all the probabilities add up to 1.
      2. \[k^2+0.4k-0.6=0\]
        Collect the numbers: 0.2 + 0.1 + 0.1 = 0.4, then subtract 1. This is a quadratic in k. The diagram plots its left side.
      3. \[(k-0.6)(k+1)=0\]
        Factorise (or use the quadratic formula). The roots are where the curve cuts the axis.
      4. \[k=0.6\ \text{ or }\ -1\ \text{(rejected)}\]
        Test k = −1: P(X = 3) = 0.4(−1) = −0.4 < 0 and P(X = 4) = (−1)² + 0.1 = 1.1 > 1. Impossible, so reject it.
      5. \[\therefore\ k=\underline{0.6}\]
        Check: 0.2 + 0.1 + 0.24 + 0.46 = 1, and every bar is between 0 and 1.
      Exam skill

      Always test each root and write "(rejected)" beside the bad one, with the reason in a short note. Markers look for this line.

      Example 9.6

      Distribution from "draw until …"

      Ex. 9A #19

      Vicky has 7 movie tickets in her handbag: 3 are for row H and 4 for row G. She draws tickets one by one randomly without replacement until she gets a row G ticket or a total of 3 tickets.

      1. (a)HG means a row H ticket then a row G ticket. List the sample space.

      5. \[P(X=3)=\frac37\times\frac26=\frac17\]
        P({HHG, HHH}) = P({HH}): once the first two are H, the 3rd draw always happens, whatever it shows.

      6. ∴ The probability distribution of \(X\):

        x123
        P(X = x)4/72/71/7

      Example 9.7

      Distribution by counting combinations

      Ex. 9A #20–25

      3 pieces of fruit are randomly selected from a basket of 6 oranges and 4 apples. X = number of oranges selected.

      1. (a)Represent the distribution of X by (i) a formula, (ii) a table.
      2. (b)Find (i) P(2 ≤ X ≤ 3), (ii) P(X < 1).
      Hint

      Choose x oranges from 6 and the rest from the 4 apples. Divide by the number of ways to choose any 3 from 10.

      Try it on paper first. Then press Start.

      1. (a)(i) The possible values of \(X\) are 0, 1, 2 and 3.

        Only 3 pieces are taken, and there are enough oranges and apples for any mix.

      2. Number of ways to select 3 pieces of fruit \(=C^{10}_3=120\)

        counts the ways to choose 3 objects from 10 when order does not matter. Each way is equally likely.

      3. Number of ways to select \(m\) oranges and \((3-m)\) apples \(=C^6_mC^4_{3-m}\)

        Choose m of the 6 oranges and 3 − m of the 4 apples. Multiply because both choices happen together. The diagram shows m = 2.
      4. \[\therefore\ P(X=x)=\frac{C^6_xC^4_{3-x}}{120}\ \text{ for } x=0,1,2,3\]
        This is the formula form.
      5. \[\text{(ii)}\ P(X=0)=\frac{C^4_3}{120}=\frac1{30},\quad P(X=1)=\frac{C^6_1C^4_2}{120}=\frac3{10}\]\[P(X=2)=\frac{C^6_2C^4_1}{120}=\frac12,\quad P(X=3)=\frac{C^6_3}{120}=\frac16\]
        x0123
        P(X = x)1/303/101/21/6
        Substitute x = 0, 1, 2, 3. Check: 4 + 36 + 60 + 20 = 120 ways.
      6. \[\text{(b)(i)}\ P(2\le X\le3)=P(X=2)+P(X=3)=\frac12+\frac16=\frac23\]
        "2 ≤ X ≤ 3" means X is 2 or 3. These events cannot happen together, so add.

      Definition 9.1 \[\mu=E(X)=x_1p_1+x_2p_2+\cdots+x_np_n=\sum xP(X=x)\]

      A weighted mean of the values of \(X\), with the probabilities as weights. It is the long-run average, so it need not be a value \(X\) can take.

      Explore

      E(X) is the balance point

      Expectation of a function \[E[g(X)]=\sum g(x)P(X=x),\qquad\text{e.g. } E(X^2)=\sum x^2P(X=x)\]
      Example

      X takes 1, 2, 3 with probabilities 0.2, 0.5, 0.3

      x123Sum

      x P(X = x)0.210.9E(X) = 2.1
      x² P(X = x)0.222.7E(X²) = 4.9
      Watch out E(X²) is not [E(X)]²

      E(X²) = 4.9 but [E(X)]² = 2.1² = 4.41. Square first, then average. The gap between them is the variance (next section).

      Note When g(X) = X

      E[g(X)] becomes E(X), the ordinary expectation.

      Example 9.9

      Expected net gain of a game

      Ex. 9B #35, 36

      A player pays $5 to toss 3 fair coins once, and gets $h² if h heads are obtained. H = number of heads.

      1. (a)Represent the distribution of H by a table.
      2. (b)Find the expectation of H.
      3. (c)$G(h) is the net gain in one game. (i) Write G(h) in terms of h. (ii) Find the expectation of the net gain.
      Hint

      Net gain = what you get − what you pay. For (c)(ii), use E[G(H)] = Σ G(h) P(H = h).

      Try it on paper first. Then press Start.

      1. (a) The possible values of \(H\) are 0, 1, 2 and 3.

        Think aloud: the sample space {HHH, HHT, HTH, THH, HTT, THT, TTH, TTT} has 8 equally likely outcomes. Group them by the number of heads.
      2. \[P(H=0)=\tfrac18,\ P(H=1)=\tfrac38,\ P(H=2)=\tfrac38,\ P(H=3)=\tfrac18\]
        h0123
        P(H = h)1/83/83/81/8
        Count the outcomes in each group and divide by 8.
      3. \[\text{(b)}\ \sum hP(H=h)=0\times\tfrac18+1\times\tfrac38+2\times\tfrac38+3\times\tfrac18=\underline{\tfrac32}\]
        The bars are symmetric about 1.5, so the balance point is 1.5.
      4. \[\text{(c)(i)}\ G(h)=\underline{h^2-5}\]
        Get $h², pay $5. The arrows map h = 0, 1, 2, 3 to gains 0 − 5 = −5, 1 − 5 = −4, 4 − 5 = −1 and 9 − 5 = 4. Each gain keeps the probability of its h.
      5. \[\text{(ii)}\ E[G(h)]=\sum G(h)P(H=h)\]\[=(0^2-5)\tfrac18+(1^2-5)\tfrac38+(2^2-5)\tfrac38+(3^2-5)\tfrac18=-2\]
        Weight each net gain by the probability of its h.

      6. ∴ The expectation of the net gain in a game is −$2.

        Negative: in the long run the player loses $2 per game. A game is fair only when the expected net gain is 0, so this game is not fair to players.
      Exam skill
      • E[G(H)] is not G(E(H)): (3/2)² − 5 = −2.75 ≠ −2.
      • "Fair game" questions: show E(net gain) = 0 or ≠ 0 and state the conclusion.

      Section 7 · 9.2B

      Variance Var(X)

      Expectation tells you the centre. Variance tells you how widely the values spread around it.

      Contributions (x − μ)² × P(X = x), stacked:

      Definition 9.2 \[\sigma^2=\operatorname{Var}(X)=E[(X-\mu)^2]=\sum (x-\mu)^2P(X=x)\]

      A more convenient formula:

      \[\operatorname{Var}(X)=E(X^2)-[E(X)]^2\]

      Standard deviation \(\sigma=\sqrt{\operatorname{Var}(X)}\), in the same unit as \(X\).

      Proof Why are the two formulas the same?
      \[\begin{aligned}\operatorname{Var}(X)&=\sum (x^2-2\mu x+\mu^2)P(X=x)\\&=\sum x^2P(X=x)-2\mu\sum xP(X=x)+\mu^2\sum P(X=x)\\&=E(X^2)-2\mu\cdot\mu+\mu^2\cdot 1=E(X^2)-\mu^2\end{aligned}\]
      Common mistakes
      • Writing E(X²) = [E(X)]².
      • Forgetting to square E(X).
      • Giving σ when asked for Var(X), or the other way round.
      • A negative variance means an arithmetic slip. Variance is never negative.
      Step through

      Building the working table

      X takes 0, 1, 2, 3 with probabilities 0.1, 0.2, 0.3, 0.4. Find E(X) and Var(X).

      Section 8 · 9.2C

      E(aX + b) and Var(aX + b)

      Class Activity 9.2: a coupon is drawn from five coupons worth $2, $4, $4, $5, $10. $X = its value, so E(X) = 5 and Var(X) = 7.2. What if every coupon becomes $(aX + b)?

      1
      0
      XY = aX + bE(Y) and E(Y) ± σ
      Expectation
      Variance
      Property 9.1 \[E(aX+b)=aE(X)+b\qquad\qquad \operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)\]

      So the standard deviation of \(aX+b\) is \(|a|\sigma\).

      Why b disappears from the variance

      Adding b slides every bar, and the mean, by the same amount. Distances from the mean do not change.

      Why a becomes a²

      Multiplying by a stretches every distance from the mean by |a|. Variance uses squared distances, so it is multiplied by a². That is also why Var(−X) = Var(X).

      Proof Two lines

      Let \(Y=aX+b\). \(E(Y)=\sum(ax+b)P(X=x)=a\sum xP(X=x)+b\sum P(X=x)=a\mu+b\).

      Each deviation is \((ax+b)-(a\mu+b)=a(x-\mu)\), so \(\operatorname{Var}(Y)=\sum a^2(x-\mu)^2P(X=x)=a^2\operatorname{Var}(X)\).

      Common mistakes
      • Var(2X + 3) = 2Var(X) + 3 ✗ → 4Var(X)
      • Var(3 − 2X) = −4Var(X) ✗ → (−2)²Var(X) = 4Var(X)

      Using the properties

      Ex. 9B #11, 12

      X has probability function \(P(X=x)=\dfrac{2-x}{10}\) for \(x=-2,-1,0,1\).

      1. (a)Find E(X) and Var(X).
      2. (b)Find E(X + 2) and Var(X + 2).
      3. (c)Find E(2X − 5) and Var(2X − 5).
      Hint

      Do (a) with a table. For (b) and (c), use the properties instead of new tables.

      Try it on paper first. Then press Start.

      1. \[\text{(a)}\ P(X=-2)=\tfrac{2-(-2)}{10}=\tfrac25,\ P(X=-1)=\tfrac3{10},\ P(X=0)=\tfrac15,\ P(X=1)=\tfrac1{10}\]

        The bars lean to the left, so the balance point is negative.
      3. \[\operatorname{Var}(X)=(-2)^2\tfrac25+(-1)^2\tfrac3{10}+0^2\tfrac15+1^2\tfrac1{10}-(-1)^2=\underline{1}\]
        E(X²) = 2, so Var(X) = 2 − 1 = 1. The amber band shows μ ± σ, from −2 to 0.
      4. \[\text{(b)}\ E(X+2)=E(X)+2=-1+2=\underline{1}\]
        Adding 2 slides every bar 2 to the right. The balance point moves 2 as well.
